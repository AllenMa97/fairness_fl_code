1、（研究课题）异构联邦学习中的群组公平优化。

2、（研究背景）该课题存在如下 3 个特点：
   1. 隐私限制：各联邦客户端不允许交互私有裸数据，服务器难以获知
      全局数据分布，难以实时调整模型参数。
   2. 统计异构：各客户端的数据分布与全局分布存在偏差。
   3. 系统异构：各客户端的计算与通信资源不一致。

3、（仍存挑战）各类联邦群组公平优化方法可视为一条涵盖"感知—调整—
   传导"三个环节的链路，各环节各存一项挑战：
   1. 感知环节：现有方法常依赖将群组相关的统计量（群组数据量、占比、
      本地公平性指标等）上传至服务器以感知群组差异，在通信层面暴露
      敏感信息，且受限于统计异构下小样本群组的估计噪声。
   2. 调整环节：现有方法多在输出空间施加公平性约束或在联邦聚合环节
      调整权重，未针对性处理同类异组样本的表征差异，难以从根源上
      保障模型群组公平性。
   3. 传导环节：现有方法多聚焦局部优化，在统计异构下难以将局部改进
      传导为全局保障。

4、（拟定方案）提出原型驱动的联邦群组公平优化方法 Prototype-Driven
   Fair Federated Learning, PDFFed。以"类-组原型（class-group
   prototype）"为统一知识载体，贯穿客户端训练、通信传输与服务器聚合，
   应对上述三个挑战。原型在各环节间传递与反馈形成闭环，使三个挑战
   在统一机制下协同解决。

5、（改造1：隐私友好的群组感知）
   5.1 动机：联邦群组公平优化不可避免地需要感知"不同群组的数据在
       模型预测中的差异"。现有方法通常把群组统计量直接上传，虽易于
       理解，但在通信层面暴露敏感信息。
   5.2 载体选择：原型（prototype）是样本集合在特征空间中的数学期望，
       概括集合的分布特性，不直接暴露个体样本。已有联邦方法将原型
       用作信息载体做表征对齐与通信聚合，但通常只按类别构建类原型，
       忽略类内子群（subgroup）结构。在统计异构下，同类异组样本的
       表征分布可能有显著差异，类原型无法刻画这种差异。
   5.3 设计：PDFFed 构建类别-群组感知原型（class-group aware
       prototype，下称类-组原型，CG Proto），同时编码类别与群组分布
       信息，作为后续群组敏感优化目标的操作基础。
   5.4 边界声明（诚实定位）：CG 原型在"通信内容"层面是隐私友好的
       ——上传的是特征均值而非群组统计量；但本地训练仍需要敏感属性
       标签。因此本文的隐私主张限定在"通信层面"，并以可选扩展章节
       给出基于本地差分隐私（LDP）的强隐私方案（见 9 节与理论证明）。

6、（改造2：基于原型的公平性与精度协同优化）
   6.1 核心观察：分布相近的两组数据，经同一分类头处理后预测分布也应
       相近。同类异组样本的表征差异（记为 Δ_rep）是群组预测差异的
       根源；在特征空间压缩 Δ_rep 有望从根源缓解不公平。
   6.2 上界控制（L_PA，特征空间）：理论分析表明 Δ_rep 越大，EO/DEO
       的上界越宽松（定理1、推论1）。PDFFed 在局部训练中引入原型
       对齐损失 L_PA = ½·Σ_l ‖μ_{g0,l} − μ_{g1,l}‖²，从源头压缩
       公平性上界（定理2）。L_PA 梯度仅进入编码器，不扰动分类器，
       规避了输出空间公平性约束的固有精度代价（引理1、定理3），
       且与任务梯度在高置信度样本上近似正交（引理2）。
   6.3 下界控制（L_conf，输出端）：特征空间对齐只能将 Δ_rep 压缩
       至由任务噪声主导的残余水平（定理2），无法保证归零。残余差经
       分类头投影后，可能使分类头对不同群组的原型给出系统性的置信度
       差异，从而抬高 EO 的下界（定理5、定理6）。为此 PDFFed 引入
       原型级置信度差异损失 L_conf，最小化同类异组原型经分类头后的
       置信度差异，压低公平性下界（定理6）。L_conf 作用于分类器参数，
       但其约束对象是原型级统计量，与样本级分类损失在优化层级上解耦。
   6.4 精度保障（L_l2l）：L_PA 与 L_conf 从上下界两侧约束公平性，
       但分类精度未被显式优化。PDFFed 引入原型级分类一致性损失
       L_l2l，显式优化本地分类器对本地原型的分类正确性；理论分析
       表明原型被正确分类时，其代表的样本误分类概率以指数速率衰减
       （引理3）。L_l2l 的梯度仅作用于分类器参数（引理4），不改变
       Δ_rep，因而不破坏 L_PA 的公平性保障。
   6.5 小结：L_PA（特征空间压上界）+ L_conf（输出端压下界）+
       L_l2l（原型层面保精度）三者可同时执行、互不冲突，分别从
       公平性上下界与精度两个维度协同优化。

7、（改造3：局部-全局双向对齐与服务器端全局校正）
   7.1 问题：上述优化均发生在客户端局部。统计异构使局部模型偏离全局
       最优，局部指标的改善未必传导为全局保障。
   7.2 双向对齐（L_l2g + L_g2l）：以全局原型为锚点实施原型-分类器
       双向对齐。L_l2g 以全局分类头约束本地原型（梯度仅进入编码器），
       保证 L_PA 对 Δ_rep 的压缩对全局分类头有意义；L_g2l 以本地
       分类头约束全局原型（梯度仅作用于分类器），防止局部分类器过拟合，
       且其一致性约束经 FedAvg 凸组合聚合后保持 margin，保证全局
       分类精度（引理7）。理论分析证明双向对齐收敛时，本地原型与全局
       原型在分类器方向的偏移 Γ_w 趋于 0（引理6）；而全局公平性指标
       仅依赖 wᵀz 的分布（定理9），故该机制精确命中"公平性从局部
       传导至全局"的需求（定理8）。
   7.3 服务器端全局后训练：聚合后以全局原型为校准代理，对聚合分类头
       做后训练，消除聚合残余的公平性偏差（定理12）。
   7.4 分工：双向对齐在训练过程内锚定双端一致性，全局后训练在聚合后
       消除残余偏差。全局精度由 L_l2l（局部精度保障）与双向对齐
       （精度从局部传导至全局）共同维护。

8、（贡献声明，按证据强度排序）
   1. 机制与理论：提出类-组原型驱动的特征空间公平性优化框架 PDFFed，
      首次在联邦设定下建立"Δ_rep → EO 上界"与"原型级置信度差异 →
      EO 下界"的可证理论链，并证明其规避输出空间公平性约束的固有
      精度代价（定理1-6，附录给出全部证明）。
   2. 系统设计：以原型为统一载体的"感知-调整-传导"闭环——CG 原型
      通信（通信层面隐私友好）、L_PA/L_conf/L_l2l 协同优化、双向
      对齐 + 服务器后训练弥合局部-全局鸿沟（引理3-7，定理7-9）。
   3. 实证：在图像/文本/表格三类任务、7 个数据集、4 种异构度上，
      与 15+ 基线方法对比；给出收敛曲线、机制验证曲线（Δ_rep/δ_conf
      随轮次变化）、消融与敏感性分析，证明 PDFFed 在公平性与精度
      上的联合优势（第 5 节）。

9、（可选扩展：差分隐私）
   若保留 DP 章节：客户端在上传原型前施加 LDP 高斯噪声，聚合后满足

   破坏性（定理11）；全局原型作为 EO 校准代理的有效性（定理12）。
   必须配套：隐私-效用曲线（ε ∈ {0.1, 0.5, 1, 2, ∞}）与噪声预算分析。
   若省略：主文隐私叙事停留在"通信层面隐私友好"，定理10-12 移入附录。

10、（相关工作：三环节 × 信息载体谱系）
   表：横向为干预环节（感知 / 调整 / 传导），纵向为信息载体
   （群组统计量 / 梯度与权重 / 原型）。
   - 群组统计量：FedFB（感知：类别-群组联合损失差异）、FedRenyi
     （感知：群组占比）、FairFed（感知：本地公平性指标）、FedFair
     （调整：EO 约束）、mFairFL（调整：DP/EO/AP 约束 + 梯度冲突缓解）、
     LoGoFair / PraFFL / FedFACT（近两年聚合/模型级公平方法）。
   - 梯度与权重：FedAvg / FedProx / Scaffold / FedNova（通用 FL，
     不处理群组公平）；FedRep / FedProto（原型用于表征对齐与聚合，
     但无群组细分，也无公平性理论保证）。
   - 原型（本文）：类-组原型贯穿感知-调整-传导三环节，每环节均有
     对应理论保证。
   定位声明：现有方法在三环节上各自只解决一部分，且大多在输出空间或
   聚合权重上做文章；PDFFed 是首个以类-组原型为统一载体、从特征空间
   同时约束 EO 上下界并在三环节闭环的方法。与"无需敏感属性"路线的
   差异（诚实说明）：该类方法以额外假设换取标签豁免，本文选择显式
   利用本地敏感属性标签换取可证性与机制清晰度，二者是互补而非竞争。

11、（实验计划概要，两层设计）
   11.1 广度层（Breadth）：全部基线 × 全部数据集 × 4 异构度 ×

        报告表格。叙事定位为"固定通信预算下的对比"。
   11.2 深度层（Depth）：每任务 1~2 个代表数据集，50~100 轮、
        fraction 0.3，出全部曲线（收敛曲线、Δ_rep/δ_conf 机制曲线、
        Pareto 前沿、置信度分布、特征可视化、消融、敏感性）。
   11.3 指标：ACC、EO^{(0)}、EO^{(1)}、EO_max、DEO、SPD(DP)、
        per-group ACC/TPR/FPR、HM（保留但并列报告），5 seeds +
        paired t-test / Wilcoxon。
   11.4 图清单（6 类）：① 收敛曲线（ACC/DEO vs 轮次）；② 公平性-
        精度 Pareto 散点（HM 前沿）；③ Δ_rep / δ_conf / L_PA / L_conf
        随轮次变化（机制验证，对应定理2/6）；④ 同类异组原型的置信度
        分布 / 特征 PCA；⑤ 消融柱状图 + λ 敏感性 + K/异构度敏感性；
