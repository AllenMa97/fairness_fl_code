# 数据说明 / Datasets Overview

本仓库 `fairness_fl_code`（PDFFed 公平联邦学习框架）在实验中使用的全部数据集，连同其联邦划分方式、任务设定、敏感属性、目录结构与获取方式，统一说明如下。

This document describes all datasets used in the experiments of the PDFFed fair federated learning framework, including federated partitioning, task settings, sensitive attributes, directory layout, and how to obtain them.

---

## 1. 概览 / Overview

数据集按其接入的任务类型分为四类：**表格分类（Tabular_CLF）**、**图像分类（IMG_CLF）**、**文本分类（SENT_CLF）**、**语音分类（AUD_CLF）**。每个数据集都会在联邦环境中被切分到多个客户端上训练，并用于评测"分类准确率 × 群组公平性"的联合目标。

Datasets are grouped into four task types: **Tabular_CLF**, **IMG_CLF**, **SENT_CLF**, and **AUD_CLF**. Each is partitioned across federated clients and evaluated on a joint objective of "accuracy × group fairness".

| 任务类型 | 加载入口 | 模型架构 |
|----------|----------|----------|
| Tabular_CLF（表格） | `main_Tabular_CLF.py` | Logistic Regression / ANN（输入维度随数据集而异） |
| IMG_CLF（图像） | `main_IMG_CLF.py` | 常规 CNN（`RegularCNN`，特征维度 512） |
| SENT_CLF（文本） | `main_SENT_CLF.py` | BERT-base-uncased 分类器 |
| AUD_CLF（语音） | `main_AUD_CLF.py`（接入中 / in progress） | Conv-RNN（对齐 FedAudio 的 `audio_conv_rnn`） |

四类任务的统一数据封装均位于 `module/dataset.py`，训练/验证/测试的设置与联邦 Dataloader 的构造位于 `module/experiment_setup.py` 与 `module/dataloader.py`。

补充说明：

- **CREMA-D 敏感属性取值规则**（`module/dataset.py#get_CREMAD_dataset`）：读取 `dataset/CREMA-D/crema_demographics.csv` 的说话人级元数据。默认 `sensitive_attribute='race'`，`race == 'Caucasian'` 编码为 1，其余种族（African-American / Asian 等）编码为 0；`Race == 'Unknown'` 的演员不参与训练与测试。命令行传 `-sensitive_attribute gender` 时改用 `sex == 'Male'` 编码为 1，且结果写入 `result_path/CREMA-D_gender/`（种族口径的主协议结果不受影响）。
- **AudioMNIST 敏感属性取值规则**（`module/dataset.py#get_AudioMNIST_dataset`）：读取 `dataset/AudioMNIST/audiomnist_speaker_meta.json` 的说话人级元数据，`gender == 'male'` 编码为 1，`gender == 'female'` 编码为 0；性别不在 {male, female} 内的说话人丢弃。
- **RAVDESS 敏感属性取值规则**（`module/dataset.py#get_RAVDESS_dataset`）：RAVDESS 说话人元数据编码在文件名中（`{modality}-{vocal}-{emotion}-{intensity}-{statement}-{repetition}-{actor}.wav`），演员编号奇数（01/03/.../23）为男性、偶数（02/04/.../24）为女性，分别编码为 1 / 0。只使用 audio-only（`modality=03`）的语音（`vocal=01`），歌曲与非音频模态文件不参与。
- 三个数据集的训练/测试划分均**按说话人分层**（同一说话人的录音不会同时出现在训练与测试集中）；联邦客户端划分则按命令行 `split_strategy` 决定（CREMA-D / RAVDESS 主实验采用 `Speaker`，见 `module/partition.py` 的 `_speaker_client_assignment`）。

## 2. 联邦划分方式 / Federated Partition

所有数据集在本地均默认为一个完整训练集；随后被切分到 `K` 个客户端上独立训练，服务端周期性地聚合（FedAvg 及其公平性变体）。具体切分策略由命令行参数 `--partition` 控制：

- **Dirichlet**（`Dirichlet01` / `Dirichlet05` / `Dirichlet1`）
  不同客户端的样本类别分布由 Dirichlet 分布抽样产生，参数越大分布越接近均匀，用于模拟标签分布异构（label skew）的非独立同分布（non-IID）场景。
- **Uniform**（即 IID）
  各客户端从训练集中均匀采样，类别分布大致一致。

测试集始终以 **Uniform / IID** 方式在客户端之间共享切分或作为全局评测集。分组公平性评测则按"敏感属性取值分组"计算各群组内与群组间的准确率、EO 等指标。

## 3. 表格数据集详解 / Tabular Datasets

表格数据集处理流程为：读取原始文件 → 过滤 → One-Hot 编码（`sklearn.OneHotEncoder`）→ 可选 PCA 降维 → 构造可被 ANN / LR 模型消费的特征向量。加载逻辑参考 `Renyi-Fair-Inference`（ADULT 注释中注明了来源）。

### 3.1 ADULT（UCI Adult / Census Income）
- 目录：`dataset/ADULT/`
- 文件：`adult.data`（训练）、`adult.test`（测试）、`AdultTrain.csv` / `AdultTest.csv`（即用特征）、`ADULT.pickle`（预处理缓存）
- 任务：预测个人年收入是否超过 50K（`>50K`→1，否则→0）
- 敏感属性：
  - `s1`：性别（`Male`→1，`Female`→0）
  - `s2`：种族（`White`→1，非白→0）
- 特征：14 个原始字段；`use_csv_file=True` 时直接使用 `Adult*.csv` 给出的数值特征（并在末尾追加 1 作为截距项），最后按列归一化（`sklearn.normalize`）；否则对原始字段 One-Hot，并可按 `mask_s1/mask_s2/mask_s1_s2/do_pca` 掩码敏感属性或做 PCA（默认 32 维）。
- 来源：UCI Machine Learning Repository（Census Income）。

### 3.2 COMPAS（ProPublica）
- 目录：`dataset/COMPAS/`
- 文件：`compas-scores-two-years.csv`、`COMPAS.pickle`
- 预处理过滤条件（对齐 ProPublica 官方 Analysis notebook）：
  - `days_b_screening_arrest` 在 [-30, 30] 内
  - `is_recid != -1`、`c_charge_degree != 0`
  - `score_text != N/A`
  - 种族仅保留 African-American 与 Caucasian
- 任务：预测被告是否不再犯罪（`is_recid==0`→1，即非再犯；否则→0）
- 敏感属性：
  - `s1`：种族（`African-American`→1，`Caucasian`→0）
  - `s2`：性别（`Male`→1，`Female`→0）
- 特征：从原始列中挑选若干列（性别、年龄段、种族、罪名等级、Prior 分数、decile 等），One-Hot 后 PCA 降至 64 维。
- 划分：随机种子 42 打乱后取前 4800 条为训练、其余为测试。
- 来源：ProPublica COMPAS 分析项目。

### 3.3 DRUG（UCI Drug Consumption）
- 目录：`dataset/DRUG/`
- 文件：`drug_consumption.data`、`DRUG.pickle`、`简单描述.txt`（本人整理的字段编码表）
- 任务：预测是否滥用挥发性物质（volatile substance abuse；标签列第 32 列，`CL0`/未使用→1，其余→0）
- 敏感属性：
  - `s1`：民族（`-0.31685`（White）→1，其余→0）
  - `s2`：性别（`row[2]<0`（Male）→1，Female→0）
- 特征：12 个量化属性（年龄、性别、教育、国家、民族、NEO-FFI-R 人格五因素、冲动性、感觉寻求等），离散化后共 32 列；One-Hot 后 PCA 降至 64 维。
- 规模：1,885 条受访记录，取前 1,600 条为训练、其余为测试。
- 来源：UCI Machine Learning Repository。

### 3.4 DUTCH（Dutch Census 2001）
- 目录：`dataset/DUTCH/`
- 文件：`dutch_census_2001.arff`、`DUTCH.pickle`、`简单描述.txt`
- 任务：以职业作为类别标签（`'5_4_9'`（高端职业）→1，`'2_1'`→0）
- 敏感属性：性别（`1`（Female）→1，`2`（Male）→0）
- 特征：取每行前 11 列做 One-Hot；不额外 PCA。
- 规模：约 60,413 条荷兰居民记录，随机种子 42 按 80/20 划分训练/测试。
- 来源：CBS（荷兰中央统计局）2001 年人口普查数据（经 `Fairness-aware Agnostic Federated Learning` 与 `Handling Conditional Discrimination` 预处理参考）。

### 3.5 ACSIncome（Retiring Adult, NeurIPS 2021）
- 目录：`dataset/ACSIncome/`
- 文件：`ACSIncome.npz`（**随仓库分发**，过滤后的原始取值缓存，约 13 MB）、`ACSIncome.pickle`（首次加载自动生成，约 10 GB）、可选 `psam_pusa.csv` / `psam_pusb.csv`（2018 ACS 1-Year PUMS 原始文件，合计约 2.2 GB）
- 任务：预测个人年收入是否超过 50K（`PINCP > 50000`→1）
- 人群过滤（对齐论文 Appendix B.1）：`AGEP > 16`、`PINCP > 100`、`WKHP > 0`、`PWGTP >= 1`，即只保留有工作的成年人。因此 50K 阈值落在该人群收入中位数附近（正类占比约 37%），不存在 UCI ADULT「几乎全为负类」的问题——这正是弃用 ADULT 的主要原因。
- 敏感属性：
  - `s1`：性别（`SEX == 1`（Male）→1，Female→0），正类占比约 52%
  - `s2`：种族（`RAC1P == 1`（White）→1，其余→0），正类占比约 78%
- 特征：10 个原始字段 `AGEP, COW, SCHL, MAR, OCCP, POBP, RELP, WKHP, SEX, RAC1P`；类别列 One-Hot（仅在训练集上 `fit`，未见取值置零）、数值列 `AGEP` / `WKHP` 用训练集均值方差做 z-score；不做 PCA，最终约 821 维。
- 划分：固定种子 1 的 80/20 随机划分（训练 1,327,693 / 测试 331,923）。
- 规模：过滤后 1,659,616 条（2018 ACS 1-Year PUMS 全量）。
- 复现路径：`ACSIncome.npz` 保存的是**过滤后、未编码**的原始取值，行序与合并后的 CSV 一致；`get_ACSIncome_dataset` 优先读它，因此 clone 仓库后无需下载 2.2 GB 原始 CSV 即可得到逐位相同的样本顺序、预处理结果与 pickle。若需从原始 CSV 重建这份缓存：

```bash
python setup_data.py --datasets ACSIncome          # 下载并解压 2018 ACS 1-Year PUMS（约 562 MB 压缩包）
python scripts/build_acsincome_npz.py --csv-dir dataset/ACSIncome \
    --output dataset/ACSIncome/ACSIncome.npz --verify
```

- 实验口径说明：本仓库先用 `s1`（性别）口径跑全部算法；若 PDFFed 在该口径上的结果不理想，再切换到 `s2`（种族）口径。两条口径共用同一份特征与划分，只有敏感属性列不同。
- 来源：Ding, Hardt, Miller & Schmidt, "Retiring Adult: New Datasets for Fair Machine Learning", NeurIPS 2021（`https://arxiv.org/abs/2108.04884`；数据取自 `https://www2.census.gov/programs-surveys/acs/data/pums/2018/1-Year/csv_pus.zip`）。

## 4. 图像数据集详解 / Image Datasets

图像数据统一使用 `CustomizedImageDataset` / `CelebaDataset` 加载并 `Resize + ToTensor`；首次读取会在 `dataset/cache/{名称}/{split}/` 下生成分片（shard）缓存（每片 5000 张）以加速后续训练。内存不足时自动切换为懒加载（`IMAGE_CACHE_LAZY=1` 可强制）。所有图像任务均为二分类，由 `RegularCNN` 处理。

### 4.1 CelebA（CelebA-HQ 标准版）
- 目录：`dataset/celeba/`
  - `Img/img_align_celeba/`：202,599 张 178×218 对齐人脸（~1.4 GB，需用 `setup_data.py` 下载）
  - `Anno/list_attr_celeba.txt`：40 个二元属性标注（自备）
  - `Eval/list_eval_partition.txt`：train(0)/val(1)/test(2) 划分（自备，含原版备份）
- 任务与敏感属性（见 `CelebaDataset.__init__` 注释：
  - 分类标签：**第 3 号属性 Attractive（外貌吸引力）**，`1`→吸引、`-1`→不吸引
  - 敏感属性：**第 21 号属性 Male（性别）**，`1`→男、`-1`→女
- 规模：训练 162,770 / 验证 19,867 / 测试 19,962。
- 来源：Liu et al., Deep Learning Face Attributes in the Wild (ICCV 2015)，新加坡国立大学 & MMLab。

> 备注：旧版 README 将该任务笼统描述为"微笑检测（Smile detection）"；实际加载代码以 **Attractive** 属性作为标签，敏感属性为性别（Male）。若你的实验或论文需要复现，请以本处代码一致的设定为准。

### 4.2 UTKFace
- 目录：`dataset/UTKFace/`
  - `img/`：24,108 张人脸图像（~1.5 GB，需下载）
  - `training_indexes.pickle`：80/20 随机划分索引（首次运行生成）
- 标签编入文件名，格式 `[age]_[gender]_[race]_[datetime].jpg`：
  - 性别：0=男，1=女
  - 种族：0=白人、1=黑人、2=亚洲人、3=印度人、4=其他（西裔/拉丁裔/中东裔）
- 任务与敏感属性：
  - 分类标签：**性别**（Male→1，Female→0）
  - 敏感属性：**种族**（`race==1`（黑人）→0，其余→1）
- 尺寸：64×64。约 80% 训练、20% 测试。
- 来源：Zhang, Song, Qi—UTKFace: A Dataset for Human Faces。

### 4.3 FairFace
- 目录：`dataset/FairFace/`
  - `fairface-img-margin025-trainval/`：训练 / 验证图像（~500 MB，需下载）
  - `fairface_label_train.csv` / `fairface_label_val.csv`：标签（自备）
- CSV 列：`file, age, gender, race, service_test`
- 任务与敏感属性（见 `get_FairFace_dataset`）：
  - 分类标签：`service_test` 二分类（`True`→1，`False`→0）
  - 敏感属性：**性别**（`Male`→1，`Female`→0）
- 规模：训练 86,744 张 + 验证 10,954 张。尺寸：224×224。
- 来源：Karkkainen & Joo, FairFace: Face Attribute Dataset（AAAI 2021），Kaggle。

> 备注：实际加载以 `service_test` 为标签、性别为敏感属性；README 中"种族分类"的描述与代码不一致，请以代码为准。

### 4.4 LFWA+（LFW 扩展标注版）
- 目录：`dataset/LFWA+/`
  - `lfw/`：13,236 张人脸子图（~100 MB，需下载）
  - `lfw_att_40.mat`：40 个二元属性标注（从驱动中获取，已备）
  - `training_indexes.pickle`：80/20 随机划分索引
- 任务与敏感属性（见 `get_LFWAPlus_dataset`）：
  - 分类标签：**第 2 号属性 Attractive（吸引力）**（1=是，0=否）
  - 敏感属性：**第 20 号属性 Male（性别）**
- 规模：13,143 张（`.mat` 标注数），约 80% 训练、20% 测试。尺寸：250×250。
- 来源：LFW 数据集 + 40 属性扩展标注（`lfw_att_40.mat`）。

## 5. 文本数据集详解 / Text Datasets

文本数据使用 BERT-base-uncased tokenizer 编码，封装为带缓存的 `MoJiDataset` / `BiosDataset`（同样是分片缓存）。`max_len` 表示截断长度。

### 5.1 moji
- 目录：`dataset/moji/`（`train.parquet` / `test.parquet`，自备）
- 列：`text`（文本）、`label`（情感类别，经 LabelEncoder 编码为 0/1）、`sa`（方言/受保护属性）
- 任务：情感二分类
- 敏感属性：英语方言（非裔美式英语 AAE / 标准美式英语 SAE）
- 规模：训练 1,613,790 / 测试 448,276。
- 来源：BERT 多语公平性基准的英文子集（AAE/SAE 方言情感语料）。

### 5.2 bios（Bias in Bios）
- 目录：`dataset/bios/`（`train.parquet` / `test.parquet`，自备）
- 列：`hard_text`（简历文本）、`profession`（职业，0-27 共 28 类）、`gender`（性别）
- 任务：职业二分类。参考 HuggingFace `LabHC/bias_in_bios` 的处理，把占比最大的 4 类（`{2,18,19,21}`，合计约 54.5%）归为 1 类，其余归为另一类。
- 敏感属性：性别（`Male`=0，`Female`=1）
- 规模：训练 257,478 / 测试 99,069。
- 来源：De-Arteaga et al., Bias in Bios（FAT* 2019），经 HuggingFace `LabHC/bias_in_bios` 预处理。

## 6. 音频数据集详解 / Audio Datasets

语音数据以 WAV 存储，模型侧统一转为时频表示（Mel 谱或 APC 预训练特征，随数据集而定）。联邦划分按**说话人 ID** 进行（speaker-disjoint split），保证同一说话人不会同时出现在训练与测试中。说话人级人口学信息以独立小文件随仓库分发，原始音频由 `setup_data.py` 从 GitHub Release 下载。

Audio is stored as WAV; features are time-frequency representations (Mel spectrogram or APC pretrained features, dataset-dependent). Federated partitioning is **speaker-disjoint**, so no speaker appears in both train and test. Speaker-level demographics ship with the repository as small files; raw audio is distributed via `setup_data.py` from GitHub Release.

### 6.1 CREMA-D（Crowd-sourced Emotional Multimodal Actors Dataset）
- 目录：`dataset/CREMA-D/`
  - `AudioWAV/`：7,442 条 16 kHz 单声道 WAV（~450 MB，需下载 / via `setup_data.py`）
  - `crema_demographics.csv`：91 位演员的人口学信息（`ActorID, Age, Sex, Race, Ethnicity`，随仓库分发）
- 文件命名：`{ActorID}_{Sentence}_{Emotion}_{Intensity}.wav`，例如 `1001_DFA_ANG_XX.wav`
  - 情感码：`ANG`（怒）/ `DIS`（厌）/ `FEA`（惧）/ `HAP`（喜）/ `NEU`（中）/ `SAD`（悲）
  - 强度：`XX`（正常）/ `LO`（低）/ `HI`（高）
- 说话人级属性（来自 `crema_demographics.csv`）：
  - 种族：Caucasian 61、African American 22、Asian 7、Unknown 1（合计 91）
  - 性别：Male 48、Female 43
  - 族裔：Not Hispanic 81、Hispanic 10
  - 年龄：20–74，均值 36.4
- 来源：Cao, Cooper, Keutmann, Gur, Nenkova, Verma, "CREMA-D: Crowd-sourced Emotional Multimodal Actors Dataset", IEEE Trans. Affective Computing, 2014。

> 备注：种族为 `Unknown` 的演员有 1 位，做二分组时需显式处理（剔除或归并），不可静默丢弃。本仓库默认以种族为主协议（结果在 `result_path/CREMA-D/`）；传 `-sensitive_attribute gender` 可切换为性别口径（结果在 `result_path/CREMA-D_gender/`），两套结果互不覆盖。

### 6.2 AudioMNIST
- 目录：`dataset/AudioMNIST/`
  - `data/{说话人编号}/*.wav`：30,000 条 48 kHz WAV（~1 GB，需下载 / via `setup_data.py`）
  - `audiomnist_speaker_meta.json`：60 位说话人的元信息（`accent, age, gender, native speaker`，随仓库分发）
- 文件命名：`{digit}_{speaker}_{index}.wav`，例如 `0_01_0.wav`
- 说话人级属性（来自 `audiomnist_speaker_meta.json`）：
  - 性别：male 48、female 12
  - 口音：German 41、其余 19（Chinese / Spanish / Italian / South Korean 等）
  - 年龄：随说话人而异
- 来源：Becker, Vielhaben, Ackermann, Müller, Lapuschkin, Samek, "AudioMNIST: Exploring Explainable Artificial Intelligence for audio analysis on a simple benchmark", Journal of the Franklin Institute, 2023。

> 备注：AudioMNIST 的性别分布极不平衡（48 : 12），以性别作敏感属性时分组公平性指标的方差会偏大；口音（41 : 19）是更均衡的备选。

### 6.3 RAVDESS（Ryerson Audio-Visual Database of Emotional Speech and Song）
- 目录：`dataset/RAVDESS/`
  - `Audio_Speech_Actors_01-24/Actor_{01..24}/*.wav`：1,440 条 48 kHz 单声道 WAV（~209 MB，需下载 / via `setup_data.py`）
  - 文件名为自描述格式，无需额外元数据文件
- 文件命名：`{modality}-{vocal}-{emotion}-{intensity}-{statement}-{repetition}-{actor}.wav`，例如 `03-01-05-01-02-01-12.wav`
  - 仅使用 `modality=03`（audio-only）且 `vocal=01`（speech）的文件；`vocal=02`（song）与非音频模态跳过
  - 情感码：`01` neutral / `02` calm / `03` happy / `04` sad / `05` angry / `06` fearful / `07` disgust / `08` surprised
- 说话人级属性（编码在演员编号中）：
  - 性别：奇数编号（01/03/.../23）为男性 12 位，偶数编号（02/04/.../24）为女性 12 位
- 标签：与 CREMA-D 同口径的 HAP-vs-rest，`emotion=03`（happy）→ 1，其余 7 类 → 0
- 划分：按演员（说话人）分层，并按性别分层，训练/测试演员互斥
- 来源：Livingstone & Russo, "The Ryerson Audio-Visual Database of Emotional Speech and Song (RAVDESS)", PLOS ONE, 2018（Zenodo record 1188976，CC BY-NC-SA 4.0）

> 备注：RAVDESS 只有 24 位演员，`Speaker` 划分下客户端数超过演员数会造成空客户端；本仓库取 `K=20`（每轮采样比例 0.1，即每轮 2 个客户端）与其余音频实验对齐。

## 8. 获取与复现 / Acquisition & Reproduction

- 表格与文本数据集（ADULT / ACSIncome / COMPAS / DRUG / DUTCH / moji / bios）以原始文件形式**内嵌在仓库中**，clone 后即可直接使用。ACSIncome 内嵌的是过滤后的 `ACSIncome.npz`（约 13 MB），原始 `psam_pus*.csv`（约 2.2 GB）仅在需要重建缓存时下载。
- 语音数据集的人口学标注文件（`CREMA-D/crema_demographics.csv`、`AudioMNIST/audiomnist_speaker_meta.json`）同样内嵌仓库；原始音频体积大，需通过脚本下载解压。
- 图像数据集仅标注文件内嵌仓库，图片需通过脚本下载解压：

```bash
# 查看全部数据集状态
python setup_data.py --list

# 下载全部或指定大数据集（从 GitHub Release v1.0-data 拉取）
python setup_data.py
python setup_data.py --datasets celeba UTKFace FairFace LFWA+
python setup_data.py --datasets CREMA-D AudioMNIST
python setup_data.py --datasets RAVDESS          # 从上游 Zenodo 下载（不可达时自动回退 ModelScope 镜像）

# 打包（用于上传 Release）
python setup_data.py --pack --datasets celeba
python setup_data.py --pack --datasets CREMA-D AudioMNIST
```

- 各入口的运行示例：

```bash
python main_Tabular_CLF.py --dataset ADULT  --algorithm PDFFed --clients 20 --partition Dirichlet05
python main_IMG_CLF.py    --dataset CelebA  --algorithm PDFFed --clients 20 --partition Dirichlet05
python main_SENT_CLF.py   --dataset moji    --algorithm PDFFed --clients 20 --partition Dirichlet05
```

> 若在运行中提示数据集缺失（`[SETUP]`），`module/experiment_setup.py` 会自动调用 `setup_data.py` 尝试下载。

> FairFace 说明：上游发布为嵌套目录 `fairface-img-margin025-trainval/{train,val}`；本仓库部分机器上图片被扁平化为 `dataset/FairFace/{train,val}`，此时用软链接（Linux symlink / Windows junction）补出嵌套路径即可，无需复制图片。
