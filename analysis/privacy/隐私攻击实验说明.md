# 隐私攻击实验说明 / Privacy Attack Experiment Notes

> 目标读者：需要向他人解释本实验的项目成员。所有结论对应 `run_attack.py` 与
> `privacy_attack_results.csv`（2026-10-19 版，含 5 算法扩展）。

## 1. 这是什么攻击？不是成员推断

**不是成员推断攻击（MIA, Membership Inference Attack）**。MIA 问的是
"某条具体样本是否在训练集里"；本实验做的是**属性推断攻击
（Attribute Inference Attack）**：

- 攻击者 = 诚实但好奇的服务器（honest-but-curious），或任何能截获
  客户端 → 服务器通信包的人。
- 攻击目标 = 推断某个客户端私有数据里**受保护组（African-American）样本
  的占比 q**。q 是 0~1 的连续值：q=0.35 表示该客户端 35% 的样本来自受保护组。
- 攻击 outcome 有两档：
  - **回归档**：直接猜 q 的数值，用 **MAE**（Mean Absolute Error，
    平均绝对误差 |q̂ − q|）衡量。MAE 越小越泄露；"无信息基线"
    （瞎猜全体平均）约 0.25-0.44（随 regime 变化）。
  - **二分类档**：猜"该客户端受保护组占多数吗（q > 0.5？）"，
    用 **AUC**（ROC 曲线下面积，标准机器学习概念）衡量。
    AUC=0.5 等于抛硬币，AUC=1.0 完美泄露。

所以你的理解正确：**攻击者截获上传内容，猜这个 Client 的 q 有多大**。

## 2. 攻击者的能力分级

| 等级 | 设定 | 现实对应 |
|---|---|---|
| 解析攻击 | 上传内容直接含 q 或其无噪统计量 | 不需要任何模型 |
| 本地 encoder | 攻击者用**自己另训的** encoder 处理原型，用带标注的辅助客户端训练回归器 | 攻击者只知算法、不知客户端模型 |
| **shared encoder（共享编码器，最强假设）** | 攻击者持有一份**与客户端同参数的 encoder**（特征提取器本身，不是隐私术语） | 服务器本来就部署/聚合过模型，接近现实 |

### "把原型映射回特征空间做分析"是什么意思

原型 p 是某个 (类别, 群组) 槽位内样本特征 f(x) 的均值：p = mean(f(x))。
encoder 是**确定函数**，所以拿到 p 的攻击者等于拿到了特征空间里的一个点。
他可以：

1. **辅助回归**：用自己的辅助数据（自带标签和敏感属性）算出各种 q 下的
   "参考原型"，训练一个 q̂ = g(p₁,…,p₄) 回归器，再套到截获的原型上；
2. **最近邻匹配**：在特征空间里搜"哪种子群的样本均值离 p 最近"，
   反推该槽位大概率来自哪个群组（encoder 共享时此法失效不了——
   因为距离度量与客户端用的完全一致）；
3. **优化重构**：解 min_x ‖f(x) − p‖，得到原型附近的代表性伪样本，
   再对这些伪样本做敏感属性分类。

encoder 不共享时，攻击者的特征空间和客户端的**对不上**，1-3 全部失准——
这就是"泄露程度由 encoder 异构性决定"的含义。

## 3. 各算法上传了什么（代码考古结论）

| 算法 | 实际上传内容 | 代码依据 | 攻击通道 | 实测（MAE/AUC） |
|---|---|---|---|---|
| FedFB / FairFed | 各群组样本量 n_s、群组正类率 r_s、类别×群组计数 | 算法定义要求 | a 群组统计量 | **0.000 / 1.000**（解析，完美泄露） |
| FedRenyi | 群组占比 r̄_k(s)——**其中 r̄_k(1) 就是 q 本身** | FederatedRenyi.py L154-171 | a 群组统计量 | **0.000 / 1.000** |
| LoGoFair | 每客户端群组条件预测统计（pos_rate/TPR/FPR per group） | LoGoFair.py L118-165 | d 公平性统计 | 0.156–0.244 / 0.55–0.94（极端偏斜下 AUC 0.91-0.94） |
| FedProto | 类别原型（**无群组结构**） | FederatedProto.py L345-357 | c 类原型 | 本地 encoder：≈无信息；shared encoder：AUC **0.96-0.98** |
| PDFFed | 类别×群组 四槽位原型 | 本方法 | b 类-组原型 | 本地 0.52-0.61；shared 最坏 0.862；+DP 噪声单调下降 |
| PraFFL | 仅 encoder 参数（超网络/偏好留本地） | PraFFL.py L242-262 | — 排除 | 不构成显式泄露 |
| mFairFL | 模型参数 + n_k（λ_k、群组损失差严格留本地） | mFairFL.py L129, L316-329 | — 排除 | 不构成显式泄露 |

**零填充 vs padded**：客户端缺某槽位样本时，原型槽填零向量（zero-fill）或
填该类平均特征（padded）。零填充满 0 本身是信息（"该客户端几乎没有这个群组"），
极端偏斜下攻击 AUC 0.94；padded 后关闭该路径（0.53）。**PDFFed 默认实现取 padded**。

**槽位（slot）**：`(类别 l, 群组 s)` 组合，二分类×二群组共 4 个槽位。

## 4. 结论与表述边界

- 可以说：**依赖群组统计量的方法族**（FedFB/FairFed/FedRenyi/LoGoFair）存在
  结构性泄露——它们的公平机制**必需**这些统计量，而统计量 ≈ 公开敏感构成；
  PDFFed 用原型替代该依赖，泄露低一个量级以上，且 DP 噪声可进一步压低而
  公平机制消费的聚合判别方向几乎无损（disc ≥ 0.994）。
- 不可以说：所有基线都泄露（PraFFL/mFairFL 不在此攻击面内）。
- 本实验是**与联邦训练解耦的信息论层面泄露对比**（针对上传内容本身的可推断性），
  不是端到端 MIA，不是训练过程攻击（梯度反演等），论文表述需守住这个范围。

---

**English TL;DR**: This is an *attribute inference attack* (not MIA): an
honest-but-curious server infers each client's protected-group proportion q
from its uploads. Group-statistic-based baselines (FedFB/FairFed/FedRenyi/
LoGoFair) leak q structurally (AUC up to 1.0); PDFFed's class-group prototypes
leak far less (AUC 0.52-0.86 depending on encoder assumption), and Gaussian
noise (PDFFed_DP) monotonically reduces leakage with negligible fairness
utility loss. PraFFL/mFairFL are excluded: their uploads contain no explicit
sensitive information. Scope: decoupled information-theoretic leakage
comparison, not end-to-end MIA.
